# CampusConnect

A LinkedIn-for-college platform, built as the byteXL DevOps + Cloud bootcamp's capstone application.
Students post updates and projects, discuss in department and placement-prep forums, and find hackathon
teammates through a project board with join-requests. An async worker turns activity into notifications.

This app is handed to you complete -- the point of Days 15-18 is not building it, it's taking it to
production: containerizing it, provisioning its cloud infrastructure with Terraform, deploying it to
Kubernetes with a real CI/CD pipeline, and observing it with Prometheus/Grafana. See
`../Capstone-CampusConnect-Overview.html` for the full architecture writeup.

## Architecture

| Service | Tech | Role |
|---|---|---|
| `frontend` | Next.js (App Router, TypeScript) | The UI, calls `api` directly from the browser |
| `api` | FastAPI + SQLAlchemy + Alembic | REST API, issues a JWT in an httpOnly cookie on login |
| `worker` | Python + RQ | Consumes events from Redis, writes `Notification` rows |
| `db` | Postgres | System of record (10 tables) |
| `redis` | Redis | Job queue for the worker |

Auth: FastAPI sets a signed JWT in an httpOnly cookie on register/login. The Next.js frontend calls the
API directly with `credentials: "include"` so the browser sends that cookie automatically -- there is no
Next.js server-side proxy in front of the API.

## Running Locally

```bash
docker compose build
docker compose up -d

# first run only: create the schema and seed the starting forums
docker compose exec api alembic upgrade head
docker compose exec api python seed.py
```

Frontend: http://localhost:3000
API docs (free, generated by FastAPI): http://localhost:8000/docs

Register two accounts (two different browsers or an incognito window) and try: post something,
comment/like from the other account, check Notifications on the first account.

## Project Structure

```
backend/
  app/
    models.py           -- all 10 SQLAlchemy models
    schemas.py            -- Pydantic request/response schemas
    security.py             -- password hashing + JWT issue/verify
    jobs.py                   -- RQ job functions (run inside the worker process)
    routers/                   -- auth, feed, forums, projects, notifications
  worker/run_worker.py          -- the background worker's entry point
  alembic/                       -- migration history
  seed.py                         -- creates the starting forums
frontend/
  app/                              -- one folder per route (Next.js App Router)
  lib/api.ts, lib/auth-context.tsx    -- API client + current-user context
compose.yaml, backend/Dockerfile*, frontend/Dockerfile
```
